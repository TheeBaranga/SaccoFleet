# Render the entity relationship diagram

Copy the contents of [erd.mmd](erd.mmd) into a Mermaid renderer or into a Markdown code block marked `mermaid` in a Mermaid-enabled viewer. See the [data dictionary](data_dictionary.md) for all fields and validation rules. Fleet is the SACCO table. Expenses, services and legacy collections derive their SACCO through existing relationships in the diagram.
