# Classroom usability tasks

Use the fictional database and sign in as operations staff. Give each participant the same three tasks and let them attempt each task without guidance.

1. Open Assignments and find the vehicle and driver for the first classroom assignment.
2. Use a free time slot on its assignment to record a daily return with a route, two trips, opening and closing readings and a reported collection. Open the saved entry and read back the calculated distance.
3. Open Daily Operations, select today's date and locate the saved session. For the manager demonstration, open Reports for the same date and follow a total to its source sessions.

Record each participant's unassisted completion per task, errors, and time taken. Divide completed task attempts by all attempts. Compare against the 80% proposal target and report participant count. The user study has not been run.
